# Hello, It's Me

A personal Hello World website by King Josh Robles for Semi-Final PIT.

## Run with XAMPP
1. Place this folder at C:\xampp\htdocs\hello-world.
2. Start Apache in the XAMPP Control Panel. MySQL is not required.
3. Open http://localhost/hello-world/.

Open this folder in VS Code to edit index.php (HTML) and assets/css/style.css.
No framework, JavaScript, database, or build step is required.

## Project files
- index.php: semantic HTML, navigation, monochrome inline SVG icons, and personal content.
- assets/css/style.css: palette, typography, and responsive layouts.
- assets/images/profile.png: portrait cutout based on the photograph supplied by King Josh Robles.
- assets/images/favicon.svg: browser tab monogram.

The page contains About Me, Education, five Favorite Songs, and five Games I Played.
The song and game lists are informational; they are not playback or launch controls.

## Replacing the portrait
Place your image in assets/images and update its path, width, height, and alt text in
index.php. Adjust `.portrait img` in assets/css/style.css for the new crop. A transparent
PNG works best. The original uploaded photo is preserved outside this repository.

The current portrait was prepared using the built-in ImageGen tool. Prompt:
"Use case: background-extraction. Edit the supplied actual portrait photograph into a
clean photographic cutout for a personal website. Remove the entire event background
including text, logos and furniture, replacing it with genuine alpha transparency.
Keep this exact man's recognizable face, skin texture, hair, silver eyeglasses,
expression, pose, and cream embroidered barong unchanged. Preserve photographic
realism; do not cartoonize, beautify, invent accessories or alter identity. Frame his
complete head with a little breathing room above, both shoulders, and visible torso
to the same bottom crop as the source. Tight portrait composition around the subject
with transparent background, smooth natural hair edges. No text, no border, no shadow,
no background colors."

## Design
The supplied reference informs the portrait-left composition, highlighted typography,
vertical student label, and grouped information panel. The navy, amber, aqua, ivory,
and coral palette is original to this version. All assets are local, and no third-party
font, icon, JavaScript, analytics, or database service is required.
